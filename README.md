# Statistical Hypothesis Testing: Lunch vs Dinner Tip Percentage

## Project Overview

This project performs statistical hypothesis testing to determine whether the average tip percentage differs between lunch and dinner transactions.

The analysis uses Python and statistical libraries to formulate hypotheses, examine assumptions, conduct an appropriate statistical test, interpret the results, and distinguish statistical significance from practical significance.

## Research Question

Is the mean tip percentage different between lunch and dinner transactions?

## Hypotheses

- **Null Hypothesis (H₀):** The population mean tip percentage is equal for lunch and dinner transactions.
- **Alternative Hypothesis (H₁):** The population mean tip percentage differs between lunch and dinner transactions.

Significance level: **α = 0.05**

## Dataset

- **Dataset:** Seaborn Tips Dataset
- **Source:** https://raw.githubusercontent.com/mwaskom/seaborn-data/master/tips.csv
- **Records:** 244 transactions
- **Main variables:** Total bill, tip, day, time, party size, and other transaction details.

The tip percentage is calculated using:

`Tip Percentage = (Tip / Total Bill) × 100`

## Methodology

The project follows these steps:

1. Load the dataset and inspect its structure.
2. Check missing values and data types.
3. Calculate tip percentage for each transaction.
4. Separate transactions into lunch and dinner groups.
5. Calculate descriptive statistics for both groups.
6. Visualise the distributions using histograms and box plots.
7. Check statistical assumptions using Shapiro-Wilk and Levene's tests.
8. Perform Welch's independent-samples t-test.
9. Calculate the test statistic, p-value, confidence interval, and effect size.
10. Interpret the results using a significance level of 0.05.

## Statistical Test

**Welch's Independent-Samples T-Test**

Welch's t-test is used because:

- Tip percentage is a continuous numerical variable.
- Lunch and dinner transactions form two independent groups.
- The test does not require equal population variances.

A two-sided test is performed because the objective is to determine whether the means differ, without assuming which group has a higher mean.

## Assumption Checks

The following tests are used:

- **Shapiro-Wilk Test:** Evaluates evidence against normality within each group.
- **Levene's Test:** Evaluates whether the group variances are equal.
- **Independence:** Assumed based on the transaction-level structure. It cannot be verified using the available dataset columns.

Welch's test is selected because it does not require equal variances.

## Results and Interpretation

The notebook calculates:

- Lunch and dinner sample sizes.
- Mean tip percentage for each group.
- Difference between group means.
- Welch's t-statistic.
- Degrees of freedom.
- Two-sided p-value.
- 95% confidence interval.
- Cohen's d effect size.

The decision is based on the p-value:

- If p-value < 0.05, reject the null hypothesis.
- If p-value ≥ 0.05, fail to reject the null hypothesis.

The report also discusses the difference between statistical significance and practical significance.

**Note:** Actual numerical results are generated by executing the notebook. No results are assumed or manually fabricated.
